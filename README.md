# Pace Calculator

A Vue 3 + TypeScript calculator for running pace, distance, and time.

Enter any two values and the app calculates the missing one. Distance can be meters, kilometers, yards, or miles. Pace is always per kilometer.

The UI is available in Spanish and English.

## Demo

Canonical: https://pace-calculator-opal.vercel.app/

GitHub Pages still redirects to that URL: https://miguelfervi.github.io/pace-calculator/

## Example

- Pace: 4:10 min/km
- Distance: 0.4 km
- Result: 1:40

## Local development

```bash
npm install
npm run dev
```

```bash
npm test
npm run build
```

Production deploys from `main` on Vercel. To refresh the GitHub Pages redirect:

```bash
npm run deploy
```
